# SWYNEX Task 2 – Exploratory Data Analysis (EDA)
## 📊 Retail Store Sales Dataset

This project is part of the **SWYNEX Data Analytics Internship – Task 2**.

The objective of this task is to perform Exploratory Data Analysis (EDA) on a cleaned retail store sales dataset and identify meaningful trends, patterns, and business insights.

## 🎯 Objective
- Understand the structure and characteristics of the dataset
- Analyze sales across different categories
- Compare payment methods and sales performance
- Analyze sales by location
- Identify statistical patterns and anomalies
- Generate meaningful business insights using data
  
## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel

## 📁 Dataset

The analysis was performed using the cleaned dataset prepared in **SWYNEX Task 1 – Data Cleaning & Preparation**.

- **Total records analyzed:** 12,575
- **Original columns:** 13
- **Analysis columns:** 14
- **Dataset type:** Retail Store Sales

## 🔍 EDA Performed

The following analysis was performed:

1.  Dataset structure and data types
2.  Missing value analysis
3.  Statistical summary
4.  Sales analysis by category
5.  Payment method analysis
6.  Location-wise sales analysis
7.  Average spending analysis
8.  Transaction date analysis
9.  Outlier detection using the IQR method
10.  Data visualization using charts

## 💡 Key Insights
## 1. Category Performance

**Butchers** generated the highest total sales among the categories, with approximately **208,118** in total spending.

**Milk Products** had the lowest total sales among the categories, at approximately **180,112**.

## 2. Payment Method

**Cash** was the most frequently used payment method with **4,310 transactions**.

It also generated the highest total spending of approximately **537,710**.

## 3. Online vs In-store

**Online transactions** generated higher total sales than in-store transactions.

- **Online:** approximately 791,401
- **In-store:** approximately 760,670

This indicates slightly stronger sales performance through the online channel.

## 4. Average Customer Spending

The overall average transaction spending was approximately **129.65**, while the median was **108.50**.

The difference between the mean and median suggests that some higher-value transactions influence the average.

## 5. Outlier Detection

Using the **IQR method**, the upper outlier threshold was approximately **403.50**.

There were **60 transactions** above this threshold, indicating a small number of unusually high-value transactions.

## 6. Category Average Spending

The **Butchers** category had the highest average transaction spending at approximately **139.12**.

**Milk Products** had the lowest average transaction spending at approximately **119.04**.

## 📈 Conclusion

The EDA revealed useful patterns in retail sales across product categories, payment methods, and sales locations.

The analysis shows that **Butchers** performed strongly in terms of total and average spending, **Cash** was the most commonly used payment method and generated the highest sales, while the **Online channel** generated slightly higher total sales than the In-store channel.

These insights can help businesses understand customer purchasing behavior and identify areas for improving sales and channel performance.
